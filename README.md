# 💰 ExpenseTrackerAI

An AI-powered personal finance management application that helps users track expenses, analyze spending habits, and receive intelligent financial insights.

---

## ✨ Features

### Current Features
- User authentication (Coming Soon)
- Add, edit, and delete transactions
- Income & expense tracking
- Dashboard with financial overview
- Monthly spending summary

### Planned AI Features
- 🤖 Automatic expense categorization
- 📈 Spending prediction
- ⚠️ Anomaly detection
- 🧾 Receipt OCR
- 💬 AI Financial Assistant
- 📊 Personalized financial insights
- 🎯 Budget recommendation
- 📉 Spending trend analysis

## 🧠 AI Features

### Automatic Expense Categorization
Automatically classify transactions into categories such as:
- Food & Beverage
- Transportation
- Shopping
- Bills
- Entertainment
- Healthcare
- Education

---

### Spending Forecast

Predict future monthly expenses using machine learning models.

---

### Spending Anomaly Detection

Detect unusual transactions based on historical spending behavior.

---

### Receipt OCR

Extract transaction information directly from receipt images.

---

### AI Financial Assistant

Chat with your financial data using natural language.

Examples:

> How much did I spend on food this month?

> What was my biggest expense last week?

> Am I spending more than usual?
